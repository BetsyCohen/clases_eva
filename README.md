## Clases de R para Eva

Este repositorio contiene materiales, ejercicios y recursos compartidos durante las clases personalizadas de R con Eva.

🚀 **Objetivo**: Acompañar el aprendizaje de Eva en el uso de R para análisis de datos, en su trabajo como analista de monitoreo evaluación en políticas públicas.

⚠️ **Advertencia** Este repo está pensado como una herramienta viva: se irá actualizando a medida que avancemos en las clases.
